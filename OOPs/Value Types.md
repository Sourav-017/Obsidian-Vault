

### Literals (raw values)

Hardcoded values in source code.

42  
3.14  
"hello"

- No name
- No storage (conceptually)
- Used directly by compiler

---

### 🔹 Variables (named storage)

#### Mutable

int x = 10;

#### Constant (`const`)

const int x = 10;

- Read-only after initialization
- Has memory address
- Can be runtime or compile-time initialized
